A development of an earlier Raspberry Pi / Python Wordclock https://github.com/Trotter73/Wordclock

This project utilizes hardware kits available from CyntechUK, https://cyntech.co.uk/wordclock & GurgleApps https://gurgleapps.com. The two kits have different word layouts but the software is configurable at runtime to use either.

The code has been developed independently in C++ rather than python and expands upon earlier works by adding eye candy and useful features, they include.

1) Selection of timezone and automatic DST adjustment.
2) User configurable "Night Mode" where the display can be dimmed or turned off.
3) Using the GurgleApps layout the '*' can be configured to indicate the current weather conditions as well as blinking seconds.
4) Various word transitions and hourly flourishes can be selected.
5) A 3D printable housing has been developed based around an ESP-32-C3 Mini and 8x8 WS2812B matrix, this has not been made available out of respect to CyntechUK & GurgleApps
